# 🎯 Cursor Rush

A fast-paced React game where players avoid moving circles with their mouse.  
The goal is to survive as long as possible without touching any circles, with real-time collision detection and dynamic difficulty.

---

## 🔍 Preview

![Cursor Rush Preview](src/assets/gameImage.png)

---

## 🚀 Features

- Real-time mouse tracking and collision detection  
- Multiple moving circles with random speed, size, and color  
- Game over if the mouse touches a circle or leaves the game area  
- Time tracking for current and highest run times  
- Interactive modals for help and game over messages  
- Responsive and visually appealing UI using Tailwind CSS  
- Subtle animations and audio feedback for enhanced gameplay  

---

## 🧠 Technologies Used

- React (Functional Components & Hooks)  
- Tailwind CSS  
- JavaScript (ES6+)  
- Flowbite React for modals  

---

## 🧩 How It Works

1. Open the game and view the help modal for instructions.  
2. Click **Start Game** to begin.  
3. Move your mouse to avoid the moving circles.  
   - Touching a circle or leaving the game area triggers **Game Over**.  
4. Survive as long as possible to set your highest run time.  
5. Restart the game anytime after losing.
